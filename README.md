# Statham Quotes — Image generation & OG pages

This repository contains a small static site with quote subpages and autogenerated Open Graph images.

This README explains how to (re)generate OG images and rebuild the quote pages.

## Prerequisites

- Node.js (>= 14) installed on your machine. On Windows, use PowerShell.
- npm available in PATH.

Note: `sharp` may require native build dependencies on some platforms. On Windows, install the supported prebuilt binaries by running `npm install` — the package should pull the correct binary. If you hit Sharp build errors, see the "Troubleshooting" section.

## Key scripts

- `scripts/generate-quote-image.js` — generates a single OG image for a quote id and saves it to `og-cache/og-{id}.jpg` by default.
- `scripts/build-quote-pages.js` — builds/regenerates all `quotes/{id}/index.html` pages and calls the image generator for each quote.

## Quick commands (PowerShell)

Open PowerShell in the repository root.

Install dependencies (if not already):

```powershell
npm install
```

Generate a single image for quote #219:

```powershell
node scripts/generate-quote-image.js 219
```

Regenerate all quote pages (and images):

```powershell
node scripts/build-quote-pages.js
```

If you want to regenerate a single quote page (image + page), run the generator then copy the image into the quote folder and run the page builder for that ID. Example (PowerShell):

```powershell
# generate image
node scripts/generate-quote-image.js 219
# copy into the quote folder (overwrites existing)
Copy-Item -Path og-cache/og-219.jpg -Destination quotes/219/og.jpg -Force
# rebuild single page (no dedicated command; re-run full builder or edit file manually)
node scripts/build-quote-pages.js
```

## Internals / notes for maintainers

- `generate-quote-image.js` uses `canvas` to draw images and `sharp` to encode to JPEG. It will create the `og-cache` directory if missing.
- The build script uses the generated `og.jpg` located in each `quotes/{id}/` directory. If you prefer to serve from the `og-cache` folder, you can adjust the build script accordingly.
- Open Graph meta tags were updated so `og:title` is `цитата №{id}` and `og:description` is the quote text.

## Troubleshooting

1. Error: `sharp(...).jpg is not a function` — Fix: Update `scripts/generate-quote-image.js` to use `.jpeg()` (already applied). If you still see errors, ensure `sharp` is installed and there are no duplicate versions. Run:

```powershell
npm ls sharp
```

If it reports missing, run:

```powershell
npm install sharp
```

2. Error: `VipsJpeg: unable to write to target` or `No such file or directory` — Ensure the `og-cache` directory exists or let the generator create it. The generator will create it automatically; insufficient permissions or locked files can still cause issues.

3. Sharp installation/build errors on Windows — try installing build tools / prerequisites:

```powershell
# install windows-build-tools (may require admin)
npm install --global --production windows-build-tools
```

Or install the official prebuilt binaries by ensuring Node version is supported and re-running `npm install`.
